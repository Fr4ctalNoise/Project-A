# Project A

A personal Jellyfin 12 plugin that adds an AniList-style social feed: watch
activity, Jellyfin Enhanced reviews, markdown text and image posts, likes and
comments. Every part of it requires a Jellyfin sign-in.

**Status:** in development (step 1 of 7, the Spike). Not ready for use.

Built for one private server and published so Jellyfin can install it from
its plugin catalog. It is not supported for other servers.

## Requirements

- Jellyfin 12.0 or newer (tested on 12.4)
- Optional: Jellyfin Enhanced 12.x (tested with 12.14.0.0)

Long one, sorry. I finally sorted out the subtitles problem on the living room TV. The short version: the app was picking the forced track because the default flag was set on the wrong stream, so every episode started with signs-only subtitles and nothing else.

If yours does the same, open the episode, choose the subtitle menu, and pick the full track once; the server remembers the choice per series after that. Took me three evenings to work out, so hopefully this saves someone the trouble.
